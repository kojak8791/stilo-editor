# Architecture Decision Records

Initial decisions are listed in [ARCHITECTURE.md §13](../ARCHITECTURE.md#13-decision-log).
Any **change** to a decision, or any new significant decision, gets an ADR here.

File name: `NNNN-short-title.md` (e.g. `0001-table-column-widths.md`). An ADR is accepted only
by the project owner.

## Template

```markdown
# NNNN — Title

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
What problem, which constraints.

## Decision
What we decided, precisely.

## Consequences
What changes in code/docs; trade-offs accepted.
```
